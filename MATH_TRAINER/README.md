# Математика 2 класс

Небольшое macOS-приложение для тренировки сложения и вычитания до 100.

- одно задание на экране;
- бесконечная случайная генерация;
- примеры вида `34 + 12`, `87 - 34`, `78 + 4 - 6`;
- ответ вводится с клавиатуры;
- правильный ответ подсвечивается зелёным;
- неправильный ответ — красным, поле ответа очищается;
- после правильного ответа автоматически появляется новый пример.
